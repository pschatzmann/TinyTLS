Detailed Description

template<typename NetClient>
class ClientTransport< NetClient >

Adapter that presents an Arduino-style client as a Transport.

Any type with connect(host, port), write(), read(), available(), connected() and stop() can be wrapped; WiFiClient and EthernetClient satisfy this. The adapter holds a reference, so the client must outlive it.

WiFiClient net;
ClientTransport<WiFiClient> transport(net);
