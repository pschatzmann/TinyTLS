Detailed Description

template<typename NetClient>
class SecureClient< NetClient >

A TLS client that owns its network client, in the style of WiFiClientSecure.

SecureClient creates the transport, the TinyTLS object and the network client itself, so an application needs only one object. Every method forwards to the TinyTLS instance, which tls() exposes for advanced configuration.

SecureClient<WiFiClient> client;
client.setTrustStore(&roots);
if (client.connect("example.com", 443)) { // ... }
