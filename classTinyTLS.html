Detailed Description

TLS 1.3 client class for Arduino and desktop C++.

TinyTLS owns the entropy pool, the random generator, the configuration and the session. The application attaches a transport once, configures verification, and then calls connect(), write(), read(), available() and stop(). The class is not copyable, because the session keeps pointers into it.

Certificate verification is on by default (VerifyMode::Required). It needs a trust store, and a time source is needed for expiry checks. Without a time source the handshake fails closed and verifyResult() reports VerifyTimeUnchecked. VerifyMode::None encrypts the connection without authenticating the server.

Timeouts need a clock (setClock()). Idle waiting is handled by an optional callback (setIdleCallback()), for example yield() or delay(1).

WiFiClient net;
ClientTransport<WiFiClient> transport(net);
TinyTLS tls;
tls.attach(transport);
tls.setTrustStore(&roots);
tls.setTimeSource(now_unix);
if (tls.connect("example.com", 443)) {
tls.write(request, request_len);
while (tls.connected()) {
while (tls.available() > 0) Serial.write(tls.read());
}
tls.stop();
}
