Detailed Description

Parsed X.509 certificate (RFC 5280 subset).

parse() decodes a DER certificate and extracts what chain validation needs: the issuer and subject names, the validity period, the basicConstraints CA flag, the subjectAltName DNS names, the signature algorithm and value, and the public key.

A Certificate refers to the DER buffer it was parsed from, which must outlive it. CertificateStore owns such buffers for trust anchors, and the TLS session parses server certificates in place inside the handshake buffer.

Only the TLS-relevant fields are read. No revocation checks are made.

Certificate c;
if (c.parse(der, len) == Error::Ok && c.matchesHost("example.com")) { // ... }
