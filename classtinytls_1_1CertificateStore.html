Detailed Description

Trust store: a fixed set of owned DER certificates.

Trust anchors are added from DER with addDer(), from PEM text with addPem(), or from either with add(). The store copies the bytes, so the caller's buffer can be released afterwards. The capacity is TINYTLS_X509_MAX_CERTS certificates of at most TINYTLS_X509_MAX_CERT_SIZE bytes each, set at compile time.

The class is not copyable, because the parsed certificates point into its storage. Keep the store alive for as long as connections use it.

CertificateStore roots;
roots.addPem(pem_text, strlen(pem_text));
tls.setTrustStore(&roots);
