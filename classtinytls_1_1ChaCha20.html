Detailed Description

ChaCha20 stream cipher (RFC 8439 sections 2.3 and 2.4).

A keystream generator with a 256-bit key, a 96-bit nonce and a 32-bit block counter. update() XORs keystream into data and can be called repeatedly, so a stream can be processed in pieces. crypt() is a one-shot convenience.

Never reuse a nonce with the same key: the keystream is then identical, and an attacker can recover the XOR of the two plaintexts.

ChaCha20 c;
c.setKey(key);
c.start(nonce, 1);
c.update(n, in, out);
