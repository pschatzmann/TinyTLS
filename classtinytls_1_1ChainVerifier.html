Detailed Description

Validates a server certificate chain against a trust store.

A verifier is created for one check, with a host name (or NULL to skip the name check), the current time (negative if unknown) and the trust store. verify() checks, in order:

  • every certificate is inside its validity period (only when a time is known),
  • the leaf names the host through a subjectAltName dNSName,
  • each certificate is issued by the next, which must be a CA,
  • the last certificate is a trust anchor, or is issued by one.

Failures are reported as VerifyFlag bits. A chain is trusted only when verify() returns Error::Ok, which requires every check to pass.

Note
Revocation (CRL, OCSP) and name constraints are not checked.
