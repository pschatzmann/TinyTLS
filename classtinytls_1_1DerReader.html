Detailed Description

Reader for consecutive DER tag-length-value elements.

next() returns the tag and content of the next element and advances the reader. expect() does the same and also checks the tag. Both accept the short and long length forms. Multi-byte tags are rejected, because certificates do not use them.

The reader copies nothing: returned pointers refer to the buffer given to the constructor.

DerReader seq(der, der_len);
const uint8_t *val; size_t len;
if (seq.expect(0x30, val, len)) { // ... }
