Detailed Description

Deterministic random bit generator (ChaCha20-based).

seed() takes 48 bytes from an Entropy pool and derives a 256-bit key. random() produces output under the current key and then rekeys with the next 32 keystream bytes, so a later compromise of the state does not reveal earlier output. Calls fail until seed() succeeds.

The TLS session uses the generator for the ClientHello random, the session ID and the X25519 private key.

Entropy entropy;
Drbg drbg;
drbg.seed(entropy);
uint8_t key[32];
drbg.random(key, sizeof(key));
