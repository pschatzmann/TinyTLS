Detailed Description

ECDSA signature verification on NIST P-256 (secp256r1, FIPS 186-4).

Construct the object once; it sets up the curve constants. ready() reports whether the setup succeeded. verify() can then be called for each signature. Points are computed in Jacobian coordinates in Montgomery form, so the only field inversion is the final conversion to affine coordinates. The public key is checked to lie on the curve.

Only verification is implemented. It works on public data only and is not constant-time, which is acceptable for verification.

EcdsaP256 curve;
Error rc = curve.verify(x, y, digest, 32, r, s); // x, y, r, s: 32 bytes each
