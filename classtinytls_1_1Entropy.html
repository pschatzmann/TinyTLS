Detailed Description

Entropy pool that mixes several sources through SHA-256.

The pool registers the platform source when it is created. Each getBytes() call gathers from every source, then expands the pool with a counter and ratchets it forward, so earlier outputs cannot be recomputed from later state. Up to MaxSources sources can be registered.

The pool is the input of Drbg::seed(); applications rarely use it directly.

Note
The class is not copyable, because the pool keeps pointers to its sources. Sources registered with addSource() must outlive the pool.
