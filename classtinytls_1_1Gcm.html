Detailed Description

AES-GCM authenticated encryption (NIST SP 800-38D).

Call setKey() once with a 16- or 32-byte AES key, then encrypt() or decrypt() for each message. Any IV length is accepted; 12 bytes is the case used by TLS 1.3. encrypt() and decrypt() may work in place. decrypt() verifies the tag in constant time before it releases any plaintext, and it zeros the output on failure.

Gcm g;
g.setKey(key, 128);
g.encrypt(iv, 12, aad, aad_len, plain, n, cipher, tag);
Error rc = g.decrypt(iv, 12, aad, aad_len, cipher, n, tag, plain);
