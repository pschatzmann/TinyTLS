Detailed Description

Incremental HMAC-SHA256 message authentication (RFC 2104).

The constructor starts a computation with a key. Keys longer than the SHA-256 block size are hashed first. start() restarts the object with a new key, so one object can compute many tags. The derived outer padding is wiped when the object is destroyed.

Hmac m(key, key_len);
m.update(data, data_len);
m.finish(tag); // tag: 32 bytes
