Detailed Description

Entropy source backed by the platform random number generator.

Behaviour per platform:

  • ESP32 (Arduino): the hardware RNG through esp_fill_random().
  • Other Arduino boards: a WEAK fallback that mixes micros() and floating analog pin noise. Add a stronger source with Entropy::addSource() before generating keys in production.
  • Desktop and tests: std::random_device.

The Entropy pool owns one instance and registers it automatically.
