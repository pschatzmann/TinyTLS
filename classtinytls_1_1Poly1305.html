Detailed Description

Poly1305 one-time authenticator (RFC 8439 section 2.5).

Poly1305 takes a 32-byte one-time key and produces a 16-byte tag. Each key must be used for one message only. ChaCha20Poly1305 derives that key itself, so applications rarely need this class directly.

The arithmetic uses five 26-bit limbs, so every product fits in 64 bits and no 128-bit type is needed. That keeps the class fast on 32-bit microcontrollers.

Poly1305 p;
p.setKey(otk);
p.update(data, len);
p.finish(tag);
