Detailed Description

Incremental SHA-256 hash (FIPS 180-4).

Feed data with update() and read the digest with finish(). For a single buffer, digest() resets the object and hashes it in one call. A Sha256 object is a value type: copying it snapshots the running state, which the TLS transcript hash relies on.

uint8_t out[Sha256::DigestSize];
Sha256 h;
h.update(part1, n1);
h.update(part2, n2);
h.finish(out);
