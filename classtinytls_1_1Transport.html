Detailed Description

Abstract byte transport used by the TLS session.

A transport represents a TCP-like connection and must not block. write() accepts what the network can take and returns 0 when it cannot accept more right now. read() returns -1 when no data is available. Implement this interface directly, or wrap an existing client type with ClientTransport.

The session never owns the transport; the caller keeps it alive while the connection is in use.
