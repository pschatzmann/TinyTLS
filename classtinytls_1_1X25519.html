Detailed Description

X25519 Diffie-Hellman key agreement on Curve25519 (RFC 7748).

The Montgomery ladder works on the u-coordinate only. publicKey() computes the public key for a 32-byte private scalar, and scalarmult() computes the shared secret with a peer's public key. Both return false for an all-zero result, which a low-order peer key produces. The caller must reject that case.

Scalars are clamped as the RFC requires, so any 32 random bytes are a valid private key.

X25519 x;
uint8_t pub[32], shared[32];
x.publicKey(priv, pub);
if (!x.scalarmult(shared, priv, peer_pub)) { // low-order peer key }
