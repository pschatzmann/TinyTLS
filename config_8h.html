◆ TINYTLS_MPI_MAX_LIMBS

#define TINYTLS_MPI_MAX_LIMBS   72

Maximum limbs per big integer. The default of 72 limbs (2304 bits) covers RSA-2048. Define a larger value for RSA-3072 (96 limbs) or RSA-4096 (130 limbs); this also raises the heap use of the signature code.

◆ TINYTLS_USE_PSRAM

#define TINYTLS_USE_PSRAM   0

Use PSRAM for large, rarely accessed buffers when the platform has it. Defaults to 1 on ESP32 (Arduino or ESP-IDF); set 0 to keep everything in RAM. If no PSRAM is present at run time, the allocation falls back to RAM.
