Detailed Description

Heap arrays with a placement hint (internal RAM or PSRAM).

Small, frequently used data should stay in internal RAM, which is fast. Large buffers that are touched rarely (session record buffers, certificate storage) can use PSRAM when the board has it. On ESP32 this uses heap_caps_malloc(MALLOC_CAP_SPIRAM); if no PSRAM is available the allocation falls back to RAM. Other platforms use malloc(). Override the PSRAM allocator with TINYTLS_PSRAM_ALLOC(n) and TINYTLS_PSRAM_FREE(p), for example for Raspberry Pi Pico boards with PSRAM.
