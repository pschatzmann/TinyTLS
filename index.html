TinyTLS

Introduction

TinyTLS is a header-only TLS 1.3 client for Arduino and desktop C++. It is written in C++11 and has no external dependencies. The high-level SecureClient class works like WiFiClientSecure, and TinyTLS runs the session over any transport you attach. Server certificates are validated against a trust store.

Installation

Arduino. Download the repository as a ZIP file and install it with Sketch > Include Library > Add .ZIP Library. Or copy the folder into your libraries directory. Then include the umbrella header:

#include <TinyTLS.h>
TinyTLS.h

Desktop (CMake). Requires a C++11 compiler and CMake 3.14 or later. The tests also need openssl on the path.

cmake -S . -B build
cmake --build build
cd build && ctest --output-on-failure

To use the headers from another CMake project, add the repository as a subdirectory and link TinyTLS::TinyTLS, or install it with cmake --install build.
