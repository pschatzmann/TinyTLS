Principles

  • Header-only, C++11. The library types live in the tinytls namespace. TinyTLS, ClientTransport and SecureClient are the only names outside it.
  • Classes, no static methods. Each component is an object with instance methods. Main classes: Sha256, Hmac, Hkdf, Aes, Gcm, ChaCha20, Poly1305, ChaCha20Poly1305, X25519, Entropy, Drbg, BigInt, Montgomery, EcdsaP256, RsaPublicKey, DerReader, Base64, PublicKey, Certificate, CertificateStore, ChainVerifier, Transport, Session.
  • Large buffers on the heap, small objects on the stack (see Platforms).
  • Configuration macros keep the TINYTLS_ prefix, because they are global.
