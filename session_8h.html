Detailed Description

TLS 1.3 client session (RFC 8446): handshake, record layer and application data.

The session is resumable. Every operation that would block returns Error::WantRead or Error::WantWrite, and the next call continues where the previous one stopped.

Scope: client only; cipher suites TLS_AES_128_GCM_SHA256 and TLS_CHACHA20_POLY1305_SHA256; X25519 key exchange; no HelloRetryRequest, client certificates, PSK, 0-RTT or resumption.
